OpenWrt для Rotek RX-23302 / ELECTRA RX23302

Своя прошивка OpenWrt (Linux 6.18) для роутера Ротек RX-23302 (Ростелеком / BeeLine / МТС). В официальном OpenWrt SoC Realtek RTL8197F не поддерживается — порт сделан с нуля: SoC, Ethernet и коммутатор RTL8367D, Wi-Fi (RTL8197G 2,4 ГГц и RTL8812FE 5 ГГц).

Текущий релиз — 0.2.1. Готовые образы: GitHub Releases.

Установка

  • Без разборки: кнопка Reset + TFTP — рекомендуемый способ, ~2 минуты
  • Через UART — если TFTP не подходит

Если что-то пошло не так

  • Восстановление заводской прошивки — заводская прошивка во втором слоте не затирается

Для разработчиков

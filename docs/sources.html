Перенос на ядро 6.18 (таймеры, DMA, proc_ops, WEXT…) этот проект GPL-2.0
Части halmac/phydm 8812F, sha256 sowarden/hh71vm-openwrt, Putpocket/iptime-a2004mu-openwrt GPL-2.0
Бинарные прошивки радио (data_rtl8197Gfw.c, data_rtl8812Ffw*.c, *.bin) поставляются в GPL-архивах производителя, не изменялись условия производителя

Сверка с копией у tobyw121 (e6d68e90, 19.10.2026): из 1880 наших файлов 1644 совпадают байт в байт, 32 изменены (перенос на 6.18), 204 добавлены: 71 — байт в байт из hh71vm (таблицы и halmac 8812F), остальные — сгенерированные из этих таблиц data_*.c, переходники compat_*, rx23302.mk, Kconfig.rx23302, config_8192cd.h, git_info.h.

Официально исходники драйвера TP-Link раздаёт через GPL Code Center: https://www.tp-link.com/us/support/gpl-code/ (модель Archer AX12 v1).

Из драйвера убраны таблицы и прошивки чужих чипов, которые наша конфигурация не собирает (WlanHAL/Data/ 8192E, 8192F, 8198F, 8814A, 8814B, 8821C, 8822B, 8822C, 8881A; data*/ 92C/92D/88E/8812/8723; pe/) — ~3 МБ. Остались только 8197G и 8812F.

Из драйвера убраны Windows-утилиты Realtek из GPL-архива (clone88xx.exe, MP_Precomp.exe, insert_halmac_in_reg_def.exe, Run4WindowsOnly.bat) — для сборки не нужны.

Удалено из дерева порта как неиспользуемое: старый драйвер rtl8192cd (40 МБ), отладочные патчи DSA rtl8365mb (730–735) и сам DSA — свитч управляется своим кодом.

Доноры, которые изучались / Reference projects

  • choryuidentify/openwrt-rtl8197f — исходный порт RTL8197F на OpenWrt (ядро 4.14).
  • Putpocket/iptime-a2004mu-openwrt — RTL8197F + RTL8367RB на ядре 6.18; CPU-тег и аппаратный NAT — изучались (идеи CPU-тега для router mode), код не копировался: наш hw NAT — порт ADCDS.
  • sowarden/hh71vm-openwrt — RTL8197FS + RTL8812FE (наша пара радио), halmac 1.6.6.6.
  • tobyw121/Openwrt_RTL — Xiaomi RD05 (RTL8197FH + RTL8367D, плата-близнец), исходники из GPL-архивов.
  • ADCDS/openwrt-dlink-dir842-r1 — D-Link DIR-842, 802.11w в старом драйвере. Источник аппаратного NAT (0.2.0): реверс-инжиниринг ASIC-таблиц RTL865xC/8197F и протокола NAPT (rtl865x_asichal.c, rtl819x_hwnat.c, SPDX GPL-2.0). Взято ~2700 строк; наш перенос — не копия байт в байт, изменения: API ядра (ndo_setup_tc/TC_SETUP_FT/FLOW_CLS_REPLACE|DESTROY|STATS вместо downstream ndo_flow_offload), VID 8/9 и раскладка гнёзд этой платы, ARP-окно подключённой WAN-сети, dstVid в nexthop = индекс netif (в доноре совпадал с VID случайно), без PPPoE. Подробности — в истории коммитов ветки (bf613f0…386bd37). Наш проект — GPL-2.0-only, донор — GPL-2.0: совместимо; заголовки SPDX в наших файлах сохранены.
